# ФП-Контроль

Локальный веб-портал для мониторинга финансового плана: загрузка Excel-подложки, распределение обязательств, отслеживание рисков и сроков. Контроль списаний и встречных доходов.

## Стек

- Python 3.9+ / Flask 3.x
- SQLite (файл `app/data/fp_portal.db`)
- Jinja2-шаблоны, без фронтенд-фреймворков
- Опционально: Ollama (локальный LLM для чата) и Telegram Bot API

## Запуск

### Локально

```bash
pip install -r requirements.txt
python run.py
# http://localhost:5001
```

### Docker

```bash
docker compose build
docker compose up -d
# http://localhost:5001
```

Подробности — в [README_DOCKER.md](README_DOCKER.md).

## Первый вход

При первом запуске создаётся один пользователь:

| Логин | Пароль | Роль |
|-------|--------|------|
| `owner` | `owner123` | Руководитель продукта |

**Сразу смените пароль** в разделе «Пользователи». Остальных пользователей создаёт owner через тот же раздел.

## Роли

- **owner** — полный доступ: импорт, настройки, управление пользователями, риски
- **team_lead** — просмотр и управление своими обязательствами
- **viewer** — только просмотр

## Конфигурация (переменные окружения)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `FP_PORTAL_SECRET` | `dev-secret-change-me` | Секретный ключ сессий |
| `OLLAMA_HOST` | `http://localhost:11434` | Адрес Ollama для чата |
| `OLLAMA_MODEL` | `qwen3:8b` | Модель Ollama |
| `FP_WHISPER_MODEL` | `small` | Размер модели Whisper (STT) |

## Структура данных


## Telegram-бот

Опциональный компонент. Запуск:

1. Создайте бота через @BotFather, получите токен
2. Запишите токен в `bot/token.txt` (файл исключён из git)
3. `python run_bot.py`
