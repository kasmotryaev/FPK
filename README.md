# ФП-Контроль

Локальный веб-портал для мониторинга финансового плана: загрузка Excel-подложки, распределение обязательств, отслеживание рисков и сроков. Контроль списаний и встречных доходов.

## Стек

- Python 3.9+ / Flask 3.x
- SQLite (файл `app/data/fp_portal.db`)
- Jinja2-шаблоны, без фронтенд-фреймворков
- Опционально: Ollama (локальный LLM для чата) и Telegram Bot API

## Запуск

### Локально

```bash
pip install -r requirements.txt
python run.py
# http://localhost:5001
```

### Docker

```bash
docker compose build
docker compose up -d
# http://localhost:5001
```

Подробности — в [README_DOCKER.md](README_DOCKER.md).

## Первый вход

При первом запуске создаётся один пользователь:

| Логин | Пароль | Роль |
|-------|--------|------|
| `owner` | `owner123` | Руководитель продукта |

**Сразу смените пароль** в разделе «Пользователи». Остальных пользователей создаёт owner через тот же раздел.

## Роли

- **owner** — полный доступ: импорт, настройки, управление пользователями, риски
- **team_lead** — просмотр и управление своими обязательствами
- **viewer** — только просмотр

## Конфигурация (переменные окружения)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `FP_PORTAL_SECRET` | `dev-secret-change-me` | Секретный ключ сессий |
| `OLLAMA_HOST` | `http://localhost:11434` | Адрес Ollama для чата |
| `OLLAMA_MODEL` | `qwen3:8b` | Модель Ollama |
| `FP_WHISPER_MODEL` | `small` | Размер модели Whisper (STT) |

## Telegram-бот

Опциональный компонент. Запуск:

1. Создайте бота через @BotFather, получите токен
2. Запишите токен в `bot/token.txt` (файл исключён из git)
3. `python run_bot.py`

## Развёртывание на Windows — пошаговая инструкция

Есть два способа: **Python напрямую** (проще, без Docker) и **Docker Desktop** (изолированный контейнер).

---

### Способ 1: Python напрямую (рекомендуется для начала)

#### Шаг 1. Установите Python

1. Откройте <https://www.python.org/downloads/> и скачайте последнюю версию Python 3.11 или 3.12 (кнопка «Download Python 3.x.x»).
2. Запустите установщик.
3. **Обязательно** поставьте галочку **«Add Python to PATH»** на первом экране установщика.
4. Нажмите «Install Now» и дождитесь завершения.
5. Проверьте установку — откройте **Командную строку** (`Win + R` → `cmd` → Enter) и выполните:
   ```cmd
   python --version
   ```
   Должно вывести: `Python 3.11.x` (или 3.12.x).

#### Шаг 2. Установите Git

1. Откройте <https://git-scm.com/download/win> и скачайте установщик.
2. Запустите его, на всех шагах можно оставить параметры по умолчанию.
3. Проверьте:
   ```cmd
   git --version
   ```

#### Шаг 3. Склонируйте репозиторий

В командной строке перейдите в папку, куда хотите положить проект, и выполните:

```cmd
cd C:\Users\ВашеИмя\Documents
git clone https://ваш-gitlab.domain/fp-portal.git
cd fp-portal
```

> Если используете ZIP-архив вместо git: распакуйте архив в папку, откройте командную строку и перейдите туда (`cd путь\к\fp-portal`).

#### Шаг 4. Создайте виртуальное окружение

```cmd
python -m venv venv
```

Активируйте его:

```cmd
venv\Scripts\activate
```

После активации в начале строки появится `(venv)`.

> **Важно:** команду активации нужно выполнять каждый раз при открытии новой командной строки. Или используйте `.bat`-файл из шага 7.

#### Шаг 5. Установите зависимости

```cmd
pip install -r requirements.txt
```

Установка занимает 1–3 минуты.

#### Шаг 6. Создайте папку для данных

```cmd
mkdir app\data
```

База данных и загруженные файлы будут храниться здесь (папка исключена из git).

#### Шаг 7. Задайте секретный ключ сессий

Для разовой проверки (ключ не сохраняется между сессиями командной строки):

```cmd
set FP_PORTAL_SECRET=ВашСекретныйКлюч123
```

Для постоянного хранения переменной:

1. Нажмите `Win + R`, введите `sysdm.cpl`, нажмите Enter.
2. Вкладка «Дополнительно» → кнопка «Переменные среды».
3. В блоке «Переменные среды пользователя» нажмите «Создать».
4. Имя: `FP_PORTAL_SECRET`, Значение: любая случайная строка (≥20 символов).
5. Нажмите ОК. **Перезапустите командную строку**, чтобы изменение вступило в силу.

#### Шаг 8. Запустите портал

```cmd
python run.py
```

В консоли появится:

```
============================================================
ФП-Контроль запущен: http://127.0.0.1:5001
============================================================
```

Откройте браузер и перейдите по адресу: **http://localhost:5001**

Войдите с логином `owner` и паролем `owner123`. Сразу смените пароль в разделе «Пользователи».

Для остановки нажмите `Ctrl + C` в командной строке.

---

#### Шаг 9 (опционально). Автозапуск при старте Windows

Создайте файл `start_portal.bat` в папке проекта со следующим содержимым:

```bat
@echo off
cd /d C:\Users\ВашеИмя\Documents\fp-portal
call venv\Scripts\activate
set FP_PORTAL_SECRET=ВашСекретныйКлюч123
start "ФП-Контроль" python run.py
```

Замените путь и ключ на свои.

**Добавление в автозапуск через Планировщик задач:**

1. Нажмите `Win + R` → введите `taskschd.msc` → Enter.
2. В правом меню выберите «Создать задачу».
3. Вкладка **Общие**: введите имя «ФП-Контроль», поставьте галочку «Выполнять для всех пользователей» (если нужно).
4. Вкладка **Триггеры** → «Создать» → выберите «При входе в систему».
5. Вкладка **Действия** → «Создать» → программа: укажите полный путь к `start_portal.bat`.
6. Вкладка **Условия**: снимите галочку «Запускать только при питании от сети».
7. Нажмите ОК.

### Способ 2: Docker Desktop

Подходит, если хотите изолированный контейнер и не настраивать Python вручную.

#### Шаг 1. Включите виртуализацию и WSL 2

1. Убедитесь, что в BIOS/UEFI включена виртуализация (Intel VT-x / AMD-V).
2. Откройте PowerShell **от имени администратора** и выполните:
   ```powershell
   wsl --install
   ```
   После завершения перезагрузите компьютер.

#### Шаг 2. Установите Docker Desktop

1. Скачайте с <https://www.docker.com/products/docker-desktop/> и установите.
2. При первом запуске Docker Desktop спросит про WSL 2 — согласитесь.
3. Дождитесь, пока в системном трее значок Docker станет зелёным («Running»).

#### Шаг 3. Склонируйте репозиторий

Откройте PowerShell или командную строку:

```powershell
cd C:\Users\ВашеИмя\Documents
git clone https://ваш-gitlab.domain/fp-portal.git
cd fp-portal
```

#### Шаг 4. Задайте секретный ключ

Откройте файл `docker-compose.yml` в текстовом редакторе (Блокнот, Notepad++, VS Code) и замените строку:

```yaml
- FP_PORTAL_SECRET=ЗАМЕНИТЕ_НА_СЛУЧАЙНУЮ_СТРОКУ
```

на строку с вашим ключом, например:

```yaml
- FP_PORTAL_SECRET=mySuperSecret_2026_portal
```

#### Шаг 5. Соберите и запустите

```powershell
docker compose build
docker compose up -d
```

Первая сборка занимает 3–7 минут. После этого портал доступен по адресу **http://localhost:5001**.

#### Управление контейнером

```powershell
# Остановить
docker compose down

# Посмотреть логи
docker compose logs -f

# Перезапустить после обновления кода
docker compose build
docker compose up -d
```

Данные хранятся в Docker-томе `fp_data` и **не теряются** при перезапуске или пересборке.

### Типовые ошибки и решения

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `'python' is not recognized` | Python не добавлен в PATH | Переустановите Python с галочкой «Add to PATH» |
| `pip install` падает с ошибкой SSL | Прокси или антивирус блокирует HTTPS | Попробуйте `pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org -r requirements.txt` |
| `error: Microsoft Visual C++...` (при установке faster-whisper) | Отсутствует компилятор C++ | Установите [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) |
| Порт 5001 занят | Другое приложение использует порт | Откройте `run.py` и замените `5001` на другой порт (например, `5002`) |
| Docker: `WSL 2 installation is incomplete` | WSL 2 не установлен | Выполните `wsl --install` в PowerShell от администратора и перезагрузитесь |
| Docker: `Error response from daemon: Ports are not available` | Порт 5001 занят | В `docker-compose.yml` замените `"5001:5001"` на `"5002:5001"` |
| База данных пустая / не создаётся | Папка `app\data` не существует | Создайте вручную: `mkdir app\data` |
